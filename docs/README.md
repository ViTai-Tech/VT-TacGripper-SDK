# 🦾 VT-TacGripper SDK 使用手册

> **版本**：1.1.0
> **平台**：Linux x86_64 · Python 3.10 / 3.12
> **适用夹爪**：VT-TacGripper-85-S、VT-TacGripper-85-L、VT-TacGripper-Slim

VT-TacGripper SDK 用于通过 USB2CANFD 适配器控制 VT 视触觉夹爪，支持设备枚举、通信配置、自动标定、手动示教、位置/力控运动与状态读取。

> 新的夹爪或更换机构后，必须先标定再运行应用代码。标定会让夹爪在机械限位处短暂受力，请确保夹爪空载、行程内无阻挡。

## 🧭 阅读约定

- `<SN>` 为 USB2CANFD 适配器序列号，可用 `list_devices` 查询；单适配器时可省略。
- 命令默认在仓库根目录执行；`--config ./devices.json` 表示把一机一码配置保存到当前目录。
- 代码中的 `vel`、`force` 均为 **0–100 百分比**，不是 rad/s 或 Nm。
- 首次使用建议使用 POS_FORCE 模式；固件不支持时再改用 POS_VEL。
- `VTacGripper` 构造默认**不使能**；运动前先调用 `enable()`。`release()` 不改变使能状态，需要失能时显式调用 `disable()`。
- 夹具/机构发生变更、重新安装电机或配置丢失后，应重新标定。
